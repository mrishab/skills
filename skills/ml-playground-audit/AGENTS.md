# ML Playground Audit

Conduct a deep product, UX, and functional audit of client-side machine learning playgrounds. Orchestrates multi-perspective subagents, prioritizes real browser interaction over DOM inspection, verifies mathematical and statistical correctness independently, and generates prioritized, evidence-backed audit reports. Use when auditing, reviewing, or testing ML playgrounds, educational data science tools, or interactive model explorers.
