# Loc Fitness

Enforces a hard 60-line cap on frontend React components (non-auto-generated). Use when frontend/src files grow too large or to refactor a component past the cap. Trigger keywords: line count, LOC, refactor component, split component, 60 lines, top files by lines of code, large file, too many lines, reduce lines.

For the canonical instructions, workflows, references, and executable scripts, see [SKILL.md](./SKILL.md).
